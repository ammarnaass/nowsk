# نُسَكّر (Nusakkir) 🕋

تطبيق إسلامي شامل وحديث مبني بنظام **Android** باستخدام **Kotlin** و **Jetpack Compose** وفق أحدث معايير **Material Design 3**. يهدف التطبيق إلى مساعدة المسلم على أداء عباداته اليومية بسكينة، دقة، وسهولة عبر واجهة عربية أصيلة تدعم اتجاه القراءة من اليمين إلى اليسار (RTL).

---

## 🌟 الميزات الرئيسية

- **🕌 مواقيت الصلاة الدقيقة والأذان**:
  - حساب أوقات الصلوات الخمس والشروق، الإمساك، ومنتصف الليل الشرعي بدقة فلكية حسب الإحداثيات الجغرافية.
  - دعم طرق الحساب الفلكية المعتمدة (أم القرى، رابطة العالم الإسلامي، الهيئة المصرية العامة للمساحة، وغيرها).
  - تنبيهات بدخول أوقات الصلاة مع إمكانية تشغيل الأذان الشريف.

- **📖 القرآن الكريم**:
  - تلاوة وتدبر السور والآيات برسم عثماني واضح.
  - شاشة قراءة متكاملة مع إمكانية حفظ علامات القراءة وتتبع التقدم.

- **📿 الأذكار وحصن المسلم**:
  - تصنيف منظم لأذكار الصباح والمساء، أذكار الصلاة، النوم والاستيقاظ، والأدعية المأثورة.
  - عداد تفاعلي لكل ذكر مع ردود فعل لمسية (Haptic Feedback) وتنبيه باكتمال التكرار.

- **🧭 بوصلة القبلة الذكية**:
  - تحديد اتجاه الكعبة المشرفة بدقة اعتماداً على مستشعرات الهاتف الجيروسكوبية وموقع المستخدم.

- **📿 المسبحة الإلكترونية الذكية**:
  - تسبيح حر ومخصص مع استهداف أعداد معينة، أصوات نقر اختيارية، واهتزازات لمسية عند كل تسبيحة.

- **🚀 تجربة ترحيبية وإعداد الأذونات في سياقها (Onboarding)**:
  - تعريف تفاعلي بميزات التطبيق للمستخدمين الجدد.
  - طلب أذونات الموقع والإشعارات بطريقة شفافة توضح أسباب الحاجة إليها مع الحفاظ الكامل على الخصوصية.

- **📢 تكامل إعلانات Google AdMob**:
  - دعم وحدات الإعلانات التكيفية (Adaptive Banners) عبر `AdManager` و `AdaptiveBannerAd`.
  - إدارة الإعلانات البينية (Interstitial) وإعلانات المكافأة (Rewarded) في مواضع مدروسة لا تقطع تدفق العبادة.

## 🛠️ البنية التقنية (Tech Stack)

- **لغة البرمجة**: Kotlin 2.0+
- **واجهة المستخدم**: Jetpack Compose مع Material 3 (M3)
- **إدارة الحالة**: ViewModel و StateFlow و Coroutines
- **قاعدة البيانات المحلية**: Room Database لحفظ التفضيلات، الأذكار، وسجلات التسبيح محلياً
- **تحديد الموقع والبوصلة**: Android Location Manager و SensorManager
- **الوسائط والصوتيات**: Android MediaPlayer للأذان والتنبيهات
- **الإعلانات**: Google Mobile Ads SDK (AdMob) v23+

## 📂 هيكل المشروع الأساسي

```text
app/src/main/java/com/example/
├── MainActivity.kt                # نقطة الانطلاق وإدارة الشاشات
├── NusakkirApplication.kt         # تهيئة الخدمات ومكتبة AdMob
├── ads/                           # وحدة إدارة إعلانات Google AdMob
│   ├── AdManager.kt               # إدارة تهيئة الإعلانات والتحميل المسبق
│   └── AdaptiveBannerAd.kt        # مكوّن الـ Composable للبانر التكيفي
├── data/                          # طبقة البيانات ونماذج الـ Room Database
├── ui/
│   ├── MainViewModel.kt           # نموذج العرض وإدارة الحالة المركزية
│   ├── screens/                   # الشاشات الرئيسية
│   │   ├── HomeScreen.kt          # الواجهة الرئيسية ومواقيت الصلاة
│   │   ├── OnboardingScreen.kt    # شاشة الترحيب والأذونات
│   │   ├── PrayerTimesDetailScreen.kt # تفاصيل المواقيت
│   │   ├── QuranReaderScreen.kt   # قارئ القرآن الكريم
│   │   ├── DhikrDetailScreen.kt   # تفاصيل الأذكار والعدادات
│   │   ├── TasbeehScreen.kt       # المسبحة الإلكترونية
│   │   ├── QiblaScreen.kt         # بوصلة القبلة
│   │   └── SettingsScreen.kt      # إعدادات التطبيق
│   └── theme/                     # لوحة الألوان والسمة الإسلامية
```

## 🚀 التشغيل والتطوير

### المتطلبات
- Android Studio Ladybug أو أحدث
- JDK 17 أو أحدث
- Android SDK 35 (الحد الأدنى المدعوم Min SDK 24)

### تشغيل المشروع
1. استنسخ المستودع (Clone) أو افتح مجلد المشروع في بيئة العمل.
2. قم ببناء المشروع عبر Gradle:
   ```bash
   gradle assembleDebug
   ```
3. لتشغيل اختبارات الـ Unit Tests:
   ```bash
   gradle :app:testDebugUnitTest
   ```

## 🔒 الخصوصية والأمان

- يتم حساب مواقيت الصلاة واتجاه القبلة محلياً أو باستخدام إحداثيات مشفرة دون جمع أو مشاركة بيانات الموقع الشخصية مع أي خوادم خارجية.
- جميع سجلات التسبيح والأذكار والتفضيلات يتم حفظها محلياً على جهاز المستخدم عبر Room Database.
